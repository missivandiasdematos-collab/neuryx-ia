# NEURYX.IA

Interface web premium para analise visual de graficos financeiros com fluxo preparado para IA Vision, upload de imagem, status de sistema, selecao de ativos e memoria evolutiva.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

O deploy e feito automaticamente pelo GitHub Pages quando houver push na branch `main`.
